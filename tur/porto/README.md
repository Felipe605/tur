# Porto

**Porto** é a primeira linguagem de programação totalmente em português para Termux.

## Características

- 🇧🇷 Sintaxe 100% em português
- 🚀 Simples e intuitiva
- 🎨 Syntax highlighting
- 📦 Package manager próprio
- ⚡ Compilado em C++

## Instalação

```bash
pkg install tur-repo
pkg install porto
```

## Uso

```bash
porto programa.pt
```

## Exemplo

```porto
escreva "Olá, Mundo!"

variavel nome = "Porto"
variavel versao = 2.0

enquanto versao < 10 faca
    escreva versao
    variavel versao = versao + 1
fim
```
